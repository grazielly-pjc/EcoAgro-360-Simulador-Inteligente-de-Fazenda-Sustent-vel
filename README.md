# EcoAgro-360-Simulador-Inteligente-de-Fazenda-Sustent-vel
O EcoAgro 360° é uma plataforma interativa desenvolvida para o Concurso Agrinho 2026 com o tema "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente".

O projeto simula a administração de uma propriedade rural sustentável, permitindo que o usuário tome decisões relacionadas ao uso da água, conservação do solo, fontes de energia e preservação ambiental. Cada escolha influencia indicadores de sustentabilidade, rentabilidade e impacto ambiental, promovendo a conscientização sobre a importância do equilíbrio entre produção agrícola e preservação dos recursos naturais.

Desenvolvido com HTML5, CSS3 e JavaScript, o site apresenta interface responsiva, recursos interativos e geração automática de relatórios, proporcionando uma experiência educativa e dinâmica para estudantes e comunidade.

## Objetivo

Conscientizar sobre práticas sustentáveis no campo através de uma simulação interativa.
Demonstrar como a tecnologia pode contribuir para a construção de um agro mais forte, produtivo e sustentável, incentivando práticas responsáveis para as futuras gerações.
